### 1. MouseUI操作マトリックス

```
5つのエリア × 3つの操作 = 15通りの操作
┌─────────────┬──────────────┬──────────────┬──────────────┐
│ エリア      │ 左クリック   │ 右クリック   │ ホイールクリック │
├─────────────┼──────────────┼──────────────┼──────────────┤
│ Main/Extra  │ → Side       │ → Temp       │ 複製         │
│ Side        │ → Main       │ → Temp       │ 複製         │
│ Temp        │ → Main       │ → Side       │ → Main       │
│ Search/Info │ → Main       │ → Side       │ 新タブ       │
└─────────────┴──────────────┴──────────────┴──────────────┘
```

### 2. 制限チェックシステム
- **デッキ制限**: 40-60枚メイン、15枚エクストラ/サイド
- **同名制限**: 3枚まで同名カード
- **禁止カード**: 制限・準制限・禁止カード完全対応
- **リアルタイム**: カード移動時の即座チェック

### 3. UI表示システム
- **画像モード**: 視覚的カード表示
- **テキストモード**: 軽量リスト表示
- **コンパクトモード**: 超省スペース表示
- **設定永続化**: ブラウザ再起動後も設定維持
