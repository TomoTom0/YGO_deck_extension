# Chrome拡張機能開発ロードマップ

## プロジェクト目標

遊戯王公式データベースのデッキ編集機能を**マスターデュエル風のマウス操作対応**に改善し、ユーザビリティを大幅に向上させるChrome拡張機能を開発する。

## 開発課題と制約

### 主要課題

1. **公式サイト仕様変更の影響**
   - 既存のChrome拡張機能が動作停止
   - HTML構造とJavaScript APIの変更
   - セキュリティポリシーの強化

2. **技術的制約**
   - 巨大なHTML（37,000トークン超）
   - 複雑なDOM構造
   - CSRFトークンとセッション管理
   - Content Security Policy制限

3. **機能要件**
   - マウスUI（ドラッグ&ドロップ）
   - デッキ管理機能の維持
   - Import/Export機能
   - 検索・フィルタリング強化

### 制約条件

- 公式サイトの機能を破壊しないこと
- ログイン・認証システムとの互換性維持
- セキュリティ規約の遵守
- パフォーマンス劣化の回避
