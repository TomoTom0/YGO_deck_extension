# 🎮 遊戯王DBデッキサポート v3.0 - インストールガイド

## 📋 概要
遊戯王公式カードデータベースのデッキ編集機能を改善するChrome拡張機能です。

## 🚀 自動インストール（推奨）

### 方法1: インストールスクリプト使用
```bash
# プロジェクトルートで実行
./install-extension.sh
```

### 方法2: HTMLガイド使用
```bash
# ブラウザでauto-install.htmlを開く
open auto-install.html
```

## 🔧 手動インストール

### ステップ1: Chrome拡張機能ページを開く
1. Chromeブラウザで `chrome://extensions/` にアクセス
2. または、Chrome メニュー → その他のツール → 拡張機能

### ステップ2: 開発者モードを有効化
1. 右上の「開発者モード」トグルスイッチをONにする

### ステップ3: 拡張機能を読み込み
1. 「パッケージ化されていない拡張機能を読み込む」をクリック
2. プロジェクトの `src/` フォルダを選択

### ステップ4: インストール確認
1. 拡張機能一覧に「遊戯王DBデッキサポート」が表示される
2. バージョン「3.0.0」が表示される

## 🎯 動作テスト

### テスト1: 基本動作確認
1. [遊戯王公式DB](https://www.db.yugioh-card.com/yugiohdb/) にアクセス
2. 右上にサポートパネルが表示されることを確認

### テスト2: デッキページでの動作確認
1. マイデッキページにアクセス
2. サポートパネルでページタイプが正しく表示される
3. 「再分析」ボタンが機能する
4. 「デバッグ表示」でページ構造が確認できる

### テスト3: ポップアップ機能確認
1. 拡張機能アイコンをクリック
2. 現在のページ情報が表示される
3. 設定ページが開ける

## 🐛 トラブルシューティング

### 拡張機能が表示されない場合
1. 開発者モードが有効になっているか確認
2. `src/` フォルダに `manifest.json` があるか確認
3. Chromeブラウザを再起動

### サポートパネルが表示されない場合
1. 遊戯王公式DBサイト（`https://www.db.yugioh-card.com/yugiohdb/*`）にアクセスしているか確認
2. コンソールエラーがないか確認（F12 → Console）
3. 拡張機能を無効化/有効化して再試行

### エラーメッセージが表示される場合
1. ブラウザコンソールでエラー内容を確認
2. 拡張機能を再読み込み
3. ページを更新

## 🔍 開発者向け情報

### デバッグ方法
1. Chrome DevTools でコンソールエラーを確認
2. 拡張機能ページで「詳細」→「エラー」を確認
3. content.js の console.log() 出力を確認

### 更新方法
1. ファイルを編集後、拡張機能ページで「更新」ボタンをクリック
2. ページを再読み込みして変更を確認

### 機能追加のヒント
- `src/js/content.js` でメイン機能を実装
- `src/css/content.css` でスタイルを調整
- Chrome Extension APIドキュメントを参照
